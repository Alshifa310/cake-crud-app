# 🍰 Cake CRUD App

A Spring Boot-based Cake Management System developed as part of a semester project. This application enables users to add, view, edit, and delete cake entries in a bakery inventory.

## 📌 Features

- ➕ Add new cakes with name, price, and description  
- 📋 View a list of all cakes  
- ✏️ Edit existing cake details  
- ❌ Delete cakes from the database  
- 📄 View cake details on a separate page  
- 🌐 Simple and responsive UI for ease of use  

## 🛠️ Technologies Used

- **Java 17**  
- **Spring Boot**  
- **Spring MVC**  
- **Maven**  
- **Thymeleaf**  
- **HTML/CSS**  
- **Bootstrap**  
- **H2 Database (in-memory)**  
- **Spring Data JPA**  

## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/Alshifa310/cake-crud-app.git
   cd cake-crud-app
   ```

2. **Import the project into your IDE (Eclipse/IntelliJ)**
   - File → Import → Existing Maven Project → Select this directory

3. **Run the application**
   - Run the main class with `@SpringBootApplication` annotation

4. **Access the app**
   - Open `http://localhost:8080` in your browser
